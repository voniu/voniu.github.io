# Zekun Wang — Personal Website

A lightweight, responsive personal portfolio focused on robotics, VLA, and real-robot project experience.

## Local development

```bash
pnpm install
pnpm dev
```

The site content lives in `index.html`, visual styling in `src/styles.css`, and small interactions in `src/main.js`.

## Production build

```bash
pnpm build
```

The output is written to `dist/`.
